## Defect found and fixed

`wireInpCanary()` ran at module scope in `app/root.tsx`. In dev, `import.meta.env.DEV` is true and the function touched `document` during SSR, so every local page 500'd with `document is not defined`. Production builds were unaffected because the call is tree-shaken. Fix: guard on `typeof document === "undefined"` in `app/lib/inp-canary.ts`.

## Dev-environment notes (not product bugs)

- Vite serves cached dev modules with HTTP 304 after a server restart; the browser kept a pre-fix `products.ts` and reported a bogus `DATA_NOTE` export error. Clearing the browser cache via CDP fixed it. If local hydration looks dead after a restart, hard-reload with cache disabled.
- Two font files 404 in `react-router dev` (`InterTight-VariableFont_wght-*.woff2`, `RedRose-VariableFont_wght-*.woff2`). Preload tags point at hashed asset names that the dev server does not serve. Cosmetic, production build is fine.
- The catalog loader caches for 5 minutes; a newly published product needs a dev-server restart (or the TTL) before the storefront shows it.
